# Calculate unsphericity curvature

Calculate unsphericity curvature, ku, from the equation Z
=ax^2+by^2+cxy+dx+ey(+f).

## Usage

``` r
ku(a, b, c, d, e)
```

## Arguments

- a:

  regression coefficient

- b:

  regression coefficient

- c:

  regression coefficient

- d:

  regression coefficient

- e:

  regression coefficient
