# Package index

## All functions

- [`AdjSD()`](https://ailich.github.io/MultiscaleDTM/reference/AdjSD.md)
  : Calculates standard deviation of bathymetry (a measure of rugosity)
  adjusted for slope
- [`BPI()`](https://ailich.github.io/MultiscaleDTM/reference/BPI.md) :
  Calculates Bathymetric Position Index
- [`DMV()`](https://ailich.github.io/MultiscaleDTM/reference/DMV.md) :
  Calculates Difference from Mean Value (DMV)
- [`DirSlp()`](https://ailich.github.io/MultiscaleDTM/reference/DirSlp.md)
  : Directional Slope
- [`Pfit()`](https://ailich.github.io/MultiscaleDTM/reference/Pfit.md) :
  Calculates multiscale slope and aspect using a local planar fit.
- [`Qfit()`](https://ailich.github.io/MultiscaleDTM/reference/Qfit.md) :
  Calculates multiscale slope, aspect, curvature, and morphometric
  features using a local quadratic fit
- [`RIE()`](https://ailich.github.io/MultiscaleDTM/reference/RIE.md) :
  Calculates Roughness Index-Elevation
- [`RelPos()`](https://ailich.github.io/MultiscaleDTM/reference/RelPos.md)
  : Calculates Relative Position of a focal cell
- [`SAPA()`](https://ailich.github.io/MultiscaleDTM/reference/SAPA.md) :
  Calculates surface area to planar area rugosity
- [`SlpAsp()`](https://ailich.github.io/MultiscaleDTM/reference/SlpAsp.md)
  : Multiscale Slope and Aspect
- [`SurfaceArea()`](https://ailich.github.io/MultiscaleDTM/reference/SurfaceArea.md)
  : Calculates surface area of a DTM
- [`TPI()`](https://ailich.github.io/MultiscaleDTM/reference/TPI.md) :
  Calculates Topographic Position Index
- [`VRM()`](https://ailich.github.io/MultiscaleDTM/reference/VRM.md) :
  Implementation of the Sappington et al., (2007) vector ruggedness
  measure
- [`annulus_window()`](https://ailich.github.io/MultiscaleDTM/reference/annulus_window.md)
  : Creates annulus focal window
- [`circle_window()`](https://ailich.github.io/MultiscaleDTM/reference/circle_window.md)
  : Creates circular focal window
- [`classify_features_ff()`](https://ailich.github.io/MultiscaleDTM/reference/classify_features_ff.md)
  : Helper function factory to classify morphometric features
- [`erupt()`](https://ailich.github.io/MultiscaleDTM/reference/erupt.md)
  : Create georeferenced version of R's built in volcano dataset
- [`explore_terrain()`](https://ailich.github.io/MultiscaleDTM/reference/explore_terrain.md)
  : Interactive Shiny app to look at terrain attributes
- [`kmax()`](https://ailich.github.io/MultiscaleDTM/reference/kmax.md) :
  Calculate max curvature
- [`kmean()`](https://ailich.github.io/MultiscaleDTM/reference/kmean.md)
  : Calculate mean curvature
- [`kmin()`](https://ailich.github.io/MultiscaleDTM/reference/kmin.md) :
  Calculate min curvature
- [`knc()`](https://ailich.github.io/MultiscaleDTM/reference/knc.md) :
  Calculate normal contour curvature
- [`kns()`](https://ailich.github.io/MultiscaleDTM/reference/kns.md) :
  Calculate normal slope line curvature
- [`ku()`](https://ailich.github.io/MultiscaleDTM/reference/ku.md) :
  Calculate unsphericity curvature
- [`outlier_filter()`](https://ailich.github.io/MultiscaleDTM/reference/outlier_filter.md)
  : Helper function to filter outliers from regression parameters using
  interquartile range
- [`tgc()`](https://ailich.github.io/MultiscaleDTM/reference/tgc.md) :
  Calculate contour geodesic torsion
